# ADR-0002：管理员创建账户与单机自托管

- 状态：已接受
- 日期：2026-08-13
- 替代：ADR-0001 中“邮箱邀请链接”的登录接入方案

## 决策

测试版部署在现有 Linux 云服务器，采用 Docker Compose 运行 Next.js 和 PostgreSQL。首个 owner 由部署环境引导创建，后续账户由 owner 在管理页面创建并交付一次显示的临时密码；用户首次登录强制改密。

测试期间仅通过 SSH 隧道、VPN 或固定来源白名单访问，不使用 Cloudflare Workers，也不直接开放应用端口。完成备案和 HTTPS 后再进入正式公网发布。

## 原因

管理员创建账户比邮箱邀请减少了邮件服务、令牌接受流程和身份提供方依赖，适合人数有限的早期团队。标准 Next.js + PostgreSQL 与现有 Docker 服务器匹配，也为后续计划、文档和审计数据服务端化提供统一事务数据库。

## 后果

- 管理员必须通过可信渠道交付临时密码；
- 测试版暂不提供自助注册、找回密码和邮件邀请；
- 账号数据库与实验业务数据可分阶段迁移；
- ADR-0001 的角色和记录模型继续有效，邀请链接部分不再实施；
- 正式公网前必须补登录限速、HTTPS、备份告警与权限测试。
