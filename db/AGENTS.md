# 数据库开发规则

本文件适用于 `db/` 下的 PostgreSQL 连接、Schema 和初始化逻辑，并继承仓库根目录规则。

## 文件职责

- `schema.ts`：当前数据库结构、关系、约束和索引的代码定义；
- `index.ts`：数据库连接和连接池配置；
- `bootstrap.ts`：首次管理员、团队和默认数据的幂等初始化。

数据库任务先读取目标表定义及其直接查询调用方。不要为了修改单个表先扫描所有页面。

## 数据规则

- Schema 变更必须同步生成新的 `drizzle/` 迁移，并读取 `drizzle/AGENTS.md`。
- 优先通过数据库约束保证唯一性、非空和引用完整性；应用校验不能替代关键数据约束。
- 保持团队数据隔离。查询和写入不得仅凭客户端提供的记录 ID 绕过团队或项目范围。
- 初始化逻辑必须幂等，容器重启不得重复创建管理员、团队或默认项目。
- 不在代码中写入真实数据库密码、生产连接串或管理员凭据。
- 连接池大小继续由环境配置控制，不能为解决局部问题无限扩大连接数。

## 验证

- 更新或新增相关持久化测试。
- 生成迁移后检查 SQL、Meta 快照和迁移日志是否一致。
- 运行 `npm test`；涉及部署启动时还要验证空数据库迁移和已有数据库升级路径。
